# Sustaining Balance

A group data analysis project on how food security needs differ by region and how they relate to agriculture, water stress and food loss.

## What is in here

- `cleaned/`: the four cleaned inputs: agricultural land use, food insecurity, food loss percentage and water stress (2023).
- `Output/final_merged_dataset_FAO_2023.xlsx`: the merged dataset used for analysis.
- `test.ipynb`: exploration and plots.

## Sources

FAO datasets, World Bank indicators and Kaggle datasets.

## Tools

Python with pandas, NumPy, Matplotlib and Seaborn, scikit-learn for modelling, GeoPandas for regional maps, and Tableau for the final visuals.
